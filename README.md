# 5000 Words — Геймифицированная платформа изучения языков

Интерактивная кроссплатформенная платформа для изучения английского языка с алгоритмом интервального повторения SM-2, дуэлями и глубокой геймификацией.

## 🏛 О проекте
**5000 Words** — это современная образовательная экосистема (доступная как адаптивное Web-приложение, так и нативный Android/iOS билд через Capacitor), которая превращает рутинное заучивание слов в увлекательное соревнование.

💡 **Ключевая концепция: SM-2 & Social Gamification**
Приложение построено вокруг научно доказанного алгоритма интервального повторения и мощных социальных механик:
- **Умное повторение:** Слова появляются именно в тот момент, когда мозг готов их забыть (Алгоритм SM-2).
- **Социальный драйв:** Лиги, друзья, ачивки и дуэли не дают бросить обучение.
- **Premium-монетизация:** Мягкие, но строгие лимиты для бесплатных пользователей, интегрированные прямо в UI через элегантные fallback'и.

## 🚀 Быстрый старт
**Бэкенд (Spring Boot)**
```bash
cd backend
./mvnw clean compile
./mvnw spring-boot:run
```
*Бэкенд запустится на http://localhost:8080*

**Фронтенд (React / Vite)**
```bash
cd frontend
npm install
npm run dev
```
*Откройте в браузере: http://localhost:5173*

## ✨ Фичи и крутые интерфейсные решения

### 1. Алгоритм SM-2 и Умные Сессии
* **Интервальное повторение:** Бэкенд автоматически вычисляет `easinessFactor` и `interval` на основе правильных и неправильных ответов. Приоритет отдается словам, которые пора повторять.
* **Тренировка сложных слов 🧠:** Кнопка быстрого запуска сессии только по тем словам, в которых пользователь чаще всего ошибался. Запускается в строгом режиме `WRITING`.

### 2. Игровые режимы внутри сессии
Во время обучения режимы плавно сменяют друг друга, не давая мозгу заскучать:
* **Classic:** Выбор из 4 вариантов.
* **Time Attack:** Таймер 30 секунд. Выполнен в виде SVG кругового прогресс-бара, плавно отсчитывающего время.
* **Survival:** Хардкорный режим на выбывание с 3 жизнями (❤️). Каждая ошибка отнимает сердце.
* **Writing:** Ручной ввод перевода (со строгой, но честной проверкой).

### 3. Геймификация и Социализация
* **Система Лиг (Черепаха 🐢 → Дракон 🐉):** Каждые 10 000 XP переводят пользователя в новую лигу. В Лидерборде отображается прогресс-бар достижения следующей лиги и фильтр только по участникам твоего уровня.
* **Дуэли:** Асинхронные PVP-матчи на 10 слов. Один игрок бросает вызов и проходит сессию, второй получает вызов и пытается побить результат первого.
* **Достижения (Ачивки):** Интерактивная горизонтальная карусель в профиле. Выполненные ачивки горят золотом, невыполненные остаются серыми.

### 4. Дизайн и UX (Native-like)
* **Dark Mode by default:** Приложение принудительно работает в красивой темной теме, снимая нагрузку с глаз при долгом обучении.
* **Кастомные селекты (LanguageSelect):** Никаких уродливых нативных `<select>` элементов. Разработаны всплывающие карточки, адаптированные под палец.
* **Моментальные попапы стрика:** Огненный (🔥) экран на 2 секунды с CSS-анимацией увеличения при продлении ежедневной серии побед.

### 5. Premium фичи и мягкие лимиты
* **Изящный Upsell:** Если бесплатный пользователь пытается изучить больше 50 новых слов в день или добавить 6-го друга, он не получает сухой алерт об ошибке. Приложение мягко перенаправляет его на красивый градиентный экран `/premium`.
* **Заморозка стрика (🧊):** Если Premium-пользователь пропустил ровно 1 день, бэкенд прощает ему это. Фронтенд реагирует специальным "ледяным" экраном "Premium спас твой стрик!".

## 🔍 Глубокое погружение в архитектуру

### ⚙️ Backend (Spring Boot & Java 21)
Бэкенд спроектирован по классической слоистой архитектуре, что обеспечивает слабую связность (loose coupling) и легкую масштабируемость:

1. **Security Layer (JWT):** 
   - Безопасность построена на `Spring Security` без использования сессий (Stateless). 
   - Каждому авторизованному пользователю выдается JWT токен.
   - Фильтр `JwtAuthenticationFilter` перехватывает все запросы (кроме `/api/auth/**`), валидирует подпись токена и помещает объект пользователя в `SecurityContextHolder`.

2. **Controller Layer:**
   - Обрабатывает входящие HTTP-запросы и валидирует данные с помощью аннотаций `jakarta.validation` (`@Valid`, `@NotBlank` и т.д.).
   - Исключения перехватываются единым `GlobalExceptionHandler` (`@RestControllerAdvice`), благодаря чему фронтенд всегда получает предсказуемый JSON в формате `{"status": 400, "message": "..."}` без страшных стектрейсов Java.

3. **Service Layer (Core Business Logic):**
   - **SM-2 Engine (`SessionService`):** Ядро приложения. Рассчитывает время следующего повторения слова. Если ответ верный, интервал увеличивается (1 день -> 3 дня -> 7 дней). Если неверный — интервал сбрасывается.
   - **Геймификация (`StreakService`, `LeagueService`):** Высчитывает текущую лигу "на лету" из `totalXp` (без дублирования данных в БД) и управляет "заморозками" стрика.
   - **Матчмейкинг (`DuelService`):** Обеспечивает асинхронные дуэли, где результаты фиксируются и сравниваются после прохождения сессии.

4. **Data Access Layer (Spring Data JPA):**
   - Использует мощь Hibernate. База данных нормализована, настроены каскадные удаления и правильные индексы (`idx_users_xp`, `idx_users_streak`) для мгновенного построения лидербордов даже при миллионах записей.

### 🎨 Frontend (React & Tailwind)
Фронтенд спроектирован как Single Page Application (SPA), максимально приближенное по ощущениям к нативному мобильному приложению:

1. **Менеджмент состояния (React Context):**
   - Избегаем "Prop Drilling" (пробрасывания пропсов через 10 слоев) с помощью контекстов: `AuthContext` (хранит токен и профиль), `ThemeContext` (управление темной темой), `ToastContext` (глобальные уведомления).

2. **Роутинг и защита путей:**
   - Настроен `react-router-dom` с разделением на `<PublicRoute>` (доступны только без токена — логин, регистрация) и `<PrivateRoute>` (основной функционал). 
   - Основные страницы обернуты в `AppLayout`, который содержит фиксированный нижний Tab Bar для мобильной навигации. Экраны сессий (`/session`, `/duel`) рендерятся без таббара для эффекта полного погружения (Full Screen).

3. **Сетевой слой (Axios Interceptors):**
   - Настроен единый инстанс Axios (`api.js`). 
   - Interceptor автоматически прикрепляет `Authorization: Bearer <token>` ко всем запросам. 
   - При получении ответа `401 Unauthorized` интерцептор автоматически разлогинивает пользователя и перекидывает на страницу входа.

4. **Анимации и UI (Tailwind CSS):**
   - Приложение активно использует кастомные классы Tailwind и CSS-переменные.
   - Попапы стрика используют аппаратное ускорение CSS (transform, scale, opacity) для 60 FPS анимаций.
   - Скрыты дефолтные скроллбары браузера (`.hide-scrollbar`), чтобы UI выглядел чисто и нативно на мобильных устройствах.
