# 5000 Words — Геймифицированная платформа изучения языков 🚀

Современное мобильное приложение для изучения иностранных слов на базе научного алгоритма SM-2, социальных механик и Premium-монетизации. Доступно как Web SPA и готово к сборке нативного Android/iOS APK через Capacitor.

---

## 🏛 О проекте

**5000 Words** — это полноценный продукт, объединяющий три ключевых направления:

- 🧠 **Умное обучение** — интервальное повторение (SM-2), 4 игровых режима, тренировка сложных слов.
- 🏆 **Глубокая геймификация** — лиги, стрики, ачивки, дуэли с друзьями, лидерборды.
- 💰 **Чёткая монетизация** — ограниченный Free-план и Premium-подписка за $3/месяц с уникальными возможностями.

## 📐 Архитектура системы

Проект разделён на два независимых модуля: **Backend** (REST API) и **Frontend** (SPA). Общение между ними — JSON по HTTP с JWT аутентификацией.

```
[ Frontend — React SPA ]
┌───────────────────────────────────────┐
│  Pages / Components                   │
│  React Context (Auth, Toast)          │
│  Axios (JWT Interceptors)             │
└──────────────────┬────────────────────┘
                   │  HTTP REST + JWT
                   ▼
[ Backend — Spring Boot ]
┌───────────────────────────────────────┐
│  JWT Filter → Controllers → Services  │
│  Spring Data JPA / Hibernate          │
└──────────────────┬────────────────────┘
                   │  JDBC
                   ▼
            [ PostgreSQL ]
```

## ✨ Ключевые фичи

### 🧠 Алгоритм SM-2
Каждое слово имеет индивидуальный интервал повторения. После правильного ответа следующая встреча откладывается (1 день → 3 → 7 → 15), после ошибки — сбрасывается. Слова появляются именно тогда, когда мозг готов их забыть.

### 🎮 Четыре игровых режима
- **Classic** — выбор из 4 вариантов перевода.
- **Time Attack** — таймер 30 секунд, реализован через SVG `<circle>` с `stroke-dashoffset` для плавной анимации.
- **Survival** — 3 жизни (❤️). Ошибка = потеря жизни. Компонент намеренно не размонтируется между словами, чтобы не сбрасывать стейт жизней.
- **Writing** — ручной ввод перевода с клавиатуры.

### 🏆 Лиги и Лидерборды
Лига вычисляется на лету из XP (`xp / 10000`) без хранения отдельного поля в БД, что исключает рассинхронизацию данных. Лидерборд фильтрует только участников текущей лиги с прогресс-баром до следующего уровня: Черепаха 🐢 → Кролик → Лиса → Сова → Волк → Пантера → Тигр → Медведь → Дракон → Феникс.

### ⚔️ Дуэли (Асинхронный PvP)
Один игрок отправляет вызов → бэкенд генерирует набор из 10 слов и сохраняет их ID → соперник принимает и получает тот же набор → после финиша обоих сравниваются точность и время. Победитель определяется автоматически (или объявляется ничья).

### 🔥🧊 Стрики и Заморозка
Ежедневный учет активности. При продлении стрика — сочный анимированный огненный экран (🔥). Если **Premium**-пользователь пропустил ровно 1 день и не использовал заморозку последние 30 дней — стрик сохраняется, появляется ледяной синий экран: "Premium спас твой стрик!".

### 🏅 Ачивки
Горизонтальная карусель в профиле. Полученные ачивки горят золотым, невыполненные — серые и полупрозрачные. Данные приходят с бэкенда и отражают реальный прогресс.

### 💳 Free vs Premium
| | Free | Premium |
|---|---|---|
| Новых слов/день | 50 | ∞ |
| Друзья | до 5 | ∞ |
| Заморозка стрика | — | ✅ раз в 30 дней |
| Цена | Бесплатно | $3.00 / месяц |

При превышении лимита фронтенд перехватывает ошибку `400` и плавно перенаправляет на `/premium` вместо сухого сообщения.
